# sequelize-authors

Учебное консольное приложение на Node.js, демонстрирующее связь между
моделями в Sequelize ORM с использованием SQLite.

## Предметная область

Реализован вариант A: **Author — Book**, связь **один-ко-многим (1:N)**.
Один автор может иметь несколько книг; каждая книга принадлежит ровно
одному автору.

### Модель Author (authors)

| Поле    | Тип     | Описание                       |
|---------|---------|---------------------------------|
| name    | STRING  | имя автора (обязательное поле)  |
| country | STRING  | страна (обязательное поле)      |

### Модель Book (books)

| Поле   | Тип     | Описание                          |
|--------|---------|-------------------------------------|
| title  | STRING  | название книги (обязательное поле)  |
| year   | INTEGER | год издания (обязательное поле)     |
| genre  | STRING  | жанр (обязательное поле)            |

### Связь

```js
Author.hasMany(Book, { foreignKey: 'authorId', as: 'books' });
Book.belongsTo(Author, { foreignKey: 'authorId', as: 'author' });
```

Внешний ключ `authorId` создаётся в таблице `books`.

## Установка

```
npm install
```

## Запуск

```
node src/index.js
```

При запуске скрипт:
1. подключается к базе данных SQLite;
2. синхронизирует модели `Author` и `Book` с учётом ассоциации;
3. создаёт автора и связанные с ним книги (используются специальные
   методы `createBook`, `addBook`, `countBooks`, появляющиеся у
   экземпляра благодаря `hasMany`);
4. выполняет запрос с жадной загрузкой (`include`) и выводит авторов
   вместе с их книгами в консоль;
5. закрывает соединение с базой данных.
